## Ejemplo

`Card` no impone estructura: pon dentro títulos, texto y acciones con las clases tipográficas del sistema.

<Canvas of={CardStories.Basic} />

## Luz que sigue al cursor

Por defecto la tarjeta tiene `spot` activo: al pasar el cursor aparece un brillo y el borde toma el color de acento. Desactívalo con `spot={false}` cuando la tarjeta tiene botones o enlaces propios, para que el brillo no compita con sus estados de hover.

<Canvas of={CardStories.Flat} />

<Callout title="Necesita el script del sitio">
  El brillo sigue las variables `--mx` y `--my`, que actualiza el componente `Spotlight` del sitio. En Storybook el brillo aparece centrado arriba, sin seguir el cursor.
</Callout>

## Rellenos

| Valor  | Relleno               | Uso                              |
| ------ | --------------------- | -------------------------------- |
| `none` | Ninguno               | Contenido a sangre (imágenes).   |
| `sm`   | `p-4`                 | Listas densas.                   |
| `md`   | `p-6`                 | Por defecto.                     |
| `lg`   | `p-6`, `sm:p-8`       | Tarjetas destacadas y bento.     |

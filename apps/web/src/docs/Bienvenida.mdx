# Design System del portafolio

<Lead>Los componentes, tokens y patrones con que está hecho el sitio. Cada página explica para qué sirve una pieza, muestra ejemplos en vivo con su código y lista sus props.</Lead>

El sistema está escrito en React 19 y Tailwind CSS 4, dentro de la app Next.js de `apps/web`. No es una librería publicada: los componentes se importan directo desde `@/ui`.

## Principios

- **Tokens antes que colores.** Todo color sale de una variable semántica, así cada componente funciona en ambos temas sin código extra.
- **Accesible por defecto.** Navegación por teclado, foco visible y estados que no dependen solo del color. El panel Accessibility de cada story corre axe.
- **Pocas piezas, bien compuestas.** `Card`, `Button` y `Badge` cubren casi todo; los patrones de la portada se arman con ellas.

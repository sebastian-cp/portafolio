# Colores

<Lead>Una paleta corta de tokens semánticos con valor propio en tema claro y oscuro. Los valores de esta página se leen en vivo de `globals.css`.</Lead>

## Cómo se usan

Cada token es una variable CSS en `:root` y se redefine en `:root[data-theme="dark"]`. Tailwind los expone como colores, así que en el marcado se usan como utilidades:

```tsx
<div className="border border-border bg-surface text-foreground">
  <p className="text-muted">Texto secundario</p>
  <a className="text-accent">Enlace</a>
</div>
```

<Callout title="Nombra la intención, no el color">
  Escribe `text-muted`, no `text-gray-600`. Así el mismo marcado funciona en ambos temas y un cambio de paleta se hace en un solo lugar.
</Callout>
